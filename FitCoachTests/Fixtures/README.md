`FitCoachV1.store` was generated by building commit `38151ee` with its original
three-model SwiftData schema (`Student`, `WorkoutSession`, `ExerciseEntry`) and
launching that app on iOS Simulator 26.5. The temporary generator only seeded
deterministic legacy records; it did not use current model code.

- Students: 3 (owner, tracked client, untracked client)
- Sessions: 3 (completed strength/cardio, planned strength, completed flexibility)
- Exercises: 4
- SHA-256: `eb9c21d37ae8b7b0223e07edfc75833c5e0105d217de14b48a5689d2cfc9620f`

The migration test copies this immutable fixture to a temporary directory,
opens it with the current model container, runs the idempotent data backfill,
validates IDs/state/sets/measurements/ledger, then closes and reopens it.
