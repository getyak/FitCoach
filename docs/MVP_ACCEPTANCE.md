# FitCoach MVP 验收标准

## 核心成功指标

| 指标 | 通过标准 |
|---|---|
| 冷启动到训练页 | 已有历史记录时不超过 10 秒、不超过 3 次点击 |
| 沿用上次 | 动作顺序、组数、实际重量/次数成为本次默认值；RPE、完成态与完成时间清空 |
| 完成一组 | 1 次点击；立即保存并启动绝对截止时间的休息计时 |
| 现场输入 | 常规重量、次数、RPE 调整不唤起键盘；备注才使用键盘 |
| 完成课程 | 明示余额变化；同一完成事件最多扣 1 节；保存失败不得显示成功 |
| 强退恢复 | 逐组草稿、当前动作、开始时间、休息截止时间均恢复 |

## 功能验收

- [x] 首页默认为“今天”，提供唯一高优先级快速开始入口。
- [x] 每组独立重量、次数、RPE、备注、完成状态。
- [x] 复制上次训练并清除本次完成数据。
- [x] 从历史训练创建模板，并为学员从模板开始。
- [x] planned / inProgress / completed / cancelled 状态明确。
- [x] 课时账本支持购买、消费、退款和调整，完成操作幂等。
- [x] 体重、腰围、体脂历史趋势，并可新增一次体测。
- [x] 完成页生成、编辑和分享总结。
- [x] JSON V2 备份覆盖组记录、体测、模板与课时流水；兼容旧格式导入。
- [x] 不追踪课时不会产生消费流水；续费通过 purchase/adjustment 流水改变余额。
- [x] 首次创建训练可直接进入训练现场；未记录任何完成组时禁止误扣课。
- [x] 已完成历史只读，继续训练必须回到受控训练现场。
- [x] 底部固定当前组主操作；休息结束前台触觉提醒，可选后台本地通知。

## UI 与无障碍验收

- 关键触点至少 44×44 pt；图标按钮有 VoiceOver 标签。
- 状态同时使用文本/符号表达，不只依赖颜色。
- 数值和计时使用等宽数字，单位可读。
- AX5 下主链路不截断且主 CTA 可点击。
- 支持 Reduce Motion 与 Reduce Transparency；关闭透明度时训练底栏使用不透明表面。
- iPhone SE、标准尺寸、Max，浅色与暗色均无关键内容遮挡。

## 数据不变量

- 余额恒等于课时流水金额之和，不用 `max(0)` 隐藏负数。
- 每次 completed transition 最多存在一个未逆转 consume。
- 撤销完成通过追加 refund 保留审计记录，不删除原消费。
- 关系子项使用稳定 UUID；动作和组使用显式 `sortIndex`。
- 关键写入显式 `context.save()`；成功 UI 只在保存返回后出现。
- 同一 V2 备份可重复导入，第二次不增加学员或课时流水。
- 旧数据回填有持久化完成标记且可重复运行，逐组、初始体测和课时流水不会重复生成。

## 当前自动化证据

- 21/21 条单元/集成测试通过，包含 exact V1 file-backed store 原地打开、迁移重复 UUID 修复、旧回填标记存在时仍执行 UUID 自愈、关闭重开后 ID/对象数/余额不变、旧版备份重复导入 no-op，以及畸形归档重复 set ID 防护。
- 6/6 条 UI 测试通过，包含完整扣课主链、两类强退恢复和 AX5 frame containment；字号注入修复后 SE 专项复跑 7.554 秒通过。
- iPhone 17 Pro 最终套件暖启动首帧 3 次平均 1.099 秒，相对标准差 1.571%。
- iPhone SE（第三代）系统 AX5 + 深色模式专项链路通过；自动化 AX5 使用测试专用 SwiftUI 环境注入，避免测试参数静默回落到默认字号。

## 发布前仍需人工验证

- 真机 VoiceOver 完整走查与触觉强度确认。
- MVP 明确为简体中文；开放其他语言前需完成全链路 String Catalog 与截图矩阵。
- exact V1 file-backed fixture 与同模拟器覆盖安装回归已通过；fixture 来自基线 `38151ee`，SHA-256 为 `eb9c21d37ae8b7b0223e07edfc75833c5e0105d217de14b48a5689d2cfc9620f`。当前为已验证的 SwiftData 推断式迁移，不等于所有 iOS 版本均已验证；正式扩大覆盖范围前需补目标系统矩阵，并在未来破坏性 schema 修改前引入 `VersionedSchema`/`SchemaMigrationPlan`。
- TestFlight Release 构建的启动时间、内存和长列表性能。
