提交问题或建议

数据在哪里？

FitCoach 的业务数据保存在当前设备。建议在“我的 → 备份与恢复”中定期导出 JSON 备份，并保存到你信任的位置。

如何恢复备份？

在“我的 → 备份与恢复”选择导入。FitCoach 会先验证文件，成功保存后才提示完成；重复导入同一新版备份不会重复增加学员或课时流水。

为什么没有休息提醒？

请在“我的”中开启休息提醒，并在系统设置中允许 FitCoach 发送通知。Live Activity 还需要系统允许“实时活动”。即使权限关闭，App 内倒计时仍会工作。

如何删除数据？

在学员详情中删除对应学员，或卸载 FitCoach 删除本机应用数据。你主动导出的备份需要在保存位置单独删除。
